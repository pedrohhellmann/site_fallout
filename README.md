☢️ Fallout — Projeto de Desenvolvimento Web

📖 Sobre o projeto

Este projeto consiste no desenvolvimento de um site temático sobre Fallout, uma famosa franquia de jogos eletrônicos ambientada em um mundo pós-apocalíptico, onde a humanidade tenta sobreviver após uma guerra nuclear.

O objetivo do site é apresentar informações sobre o universo de Fallout, explorando sua história, jogos, personagens, facções e curiosidades.

🎮 Tema

Fallout — O mundo após a guerra nuclear.

O site será inspirado na identidade visual da franquia, utilizando elementos como o visual retrô-futurista, o estilo dos anos 1950, os abrigos subterrâneos Vault-Tec e o cenário devastado do mundo pós-apocalíptico.

🎯 Objetivos

Apresentar a franquia Fallout e sua história.

Mostrar os principais jogos da série.

Apresentar personagens importantes.

Explicar as principais facções do universo.

Compartilhar curiosidades sobre o mundo de Fallout.

🗂️ Estrutura do site

O site poderá ser dividido nas seguintes seções:

Início: apresentação do universo Fallout.

Jogos: informações sobre os principais títulos da franquia.

História: explicação sobre a Grande Guerra e o mundo pós-apocalíptico.

Personagens: apresentação de personagens importantes.

Facções: informações sobre grupos como a Irmandade de Aço, os Minutemen e a Enclave.

Curiosidades: fatos interessantes sobre a franquia.

🛠️ Tecnologias utilizadas

HTML5 — Estrutura das páginas.

CSS3 — Estilização e aparência visual.

JavaScript — Possíveis interações e funcionalidades.

🎨 Identidade visual

O design será inspirado na estética de Fallout, utilizando:

Cores predominantes: verde, amarelo, preto e tons de marrom.

Elementos visuais inspirados na tecnologia retrofuturista.

Imagens dos jogos e personagens.

Fontes e elementos que remetem aos computadores e terminais da Vault-Tec.

📌 Considerações finais

A proposta deste projeto é desenvolver um site informativo e visualmente inspirado no universo de Fallout, utilizando os conhecimentos adquiridos durante as aulas de desenvolvimento web e explorando os recursos oferecidos pelo HTML, CSS e JavaScript.
